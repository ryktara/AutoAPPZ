| Horizon | Theme | Milestones |
|---|---|---|

| **5 — Harden** | Benchmarks, accessibility, security suite, diagnostics bundles, release engineering | M14 |
| **Later** | Browser/remote host via WebSocket transport, container-first runtime, team features (shared memory, review), semantic retrieval plugin, mobile shells | — |
