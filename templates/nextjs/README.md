# Next.js app

- `pnpm install`
- `pnpm dev` — start the dev server (`--port <n>` to choose a port)
- `pnpm build` — production build
- `pnpm start` — serve the production build
- `pnpm test` — unit tests (Vitest)
- `pnpm typecheck` — TypeScript

This project is a plain Next.js application and has no dependency on the tool that generated it. Deploy it to Vercel (source upload) or build the included `Dockerfile`.
