# templates

Bundled project templates. Available: `react-vite`, `fullstack-postgres` (React + Vite, Hono API, Drizzle migrations, cookie-session auth, notes CRUD on PostgreSQL), `nextjs` (App Router + Vitest), `dashboard` (KPIs, SVG chart, sortable table). Each ships a `Dockerfile`. Deferred: `saas` (needs the payments integration design first). Written independently in M2; no template files are copied from any reference project.
